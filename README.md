# Hidden Horizon

**Hidden Horizon** is my first web development project created with **HTML5** and **CSS3** as part of the **first module of the Software Development course at the Digital Career Institute (DCI)**.

The goal of this project was to build a fully responsive landing page while applying the fundamental concepts of semantic HTML, CSS styling and responsive web design.

## Project Overview

Hidden Horizon is a fictional luxury hotel brand offering exclusive tropical destinations and premium travel experiences.

I chose this topic because of my professional background and academic education in the tourism industry. This experience helped me approach the project from a user-focused perspective, considering the expectations and needs of travelers while designing the website.

## Development Process

This project was developed following the typical stages of a web design workflow:

- Research and concept development
- Wireframing and content planning
- HTML structure using semantic elements
- CSS styling with Flexbox
- Responsive design for mobile and desktop devices
- Testing and optimization

## Features

- Responsive design
- Semantic HTML5
- CSS3 with Flexbox
- Internal navigation
- Contact form
- Hover effects and interactive elements
- Mobile-first responsive adjustments

## Technologies

- HTML5
- CSS3
- Flexbox
- Git
- GitHub
